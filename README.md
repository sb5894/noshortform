# Noshortform

Kotlin 및 Jetpack Compose 기반의 개발용 YouTube 접근성 이벤트 관찰·차단 프로토타입입니다.

## 현재 체크포인트

- 사용자 기기에서 차단 스위치가 꺼져 있으면 Shorts를 계속 볼 수 있음을 확인했습니다.
- 차단을 켠 상태에서는 Shorts 첫 진입 시 화면이 유지됐고, 다음 영상으로 넘기면 뒤로 이동했습니다.
- 이 동작은 현재 기기의 관찰 결과이며, 의도적으로 첫 영상 한 개를 허용하도록 구현된 것은 아닙니다.
- 이전 관찰 테스트에서는 첫 진입에도 후보 ID가 나온 적이 있어, 첫 진입 차단 실패 원인은 아직 확정되지 않았습니다.

## 구현 범위

- 디버그 빌드에서 YouTube 이벤트만 처리합니다.
- 정확한 뷰 ID `com.google.android.youtube:id/reel_player_page_container`를 Shorts 근거로 사용합니다.
- 차단 설정은 기본 꺼짐이며 기기에 유지됩니다. 해당 설정은 백업에서 제외됩니다.
- 뒤로 가기 요청 사이에 2초 제한을 적용하고, 발생 후 1초를 넘긴 이벤트는 차단하지 않습니다.
- Logcat 태그는 `YouTubeEventObserver`이며 패키지명, 이벤트 종류, 클래스명, 뷰 ID, `shortsEvidence`만 출력합니다.
- 화면 내용·영상 제목·이미지·로그 파일을 저장하지 않으며 네트워크 권한과 외부 분석 SDK를 사용하지 않습니다.

## 검증

디버그 단위 테스트 14개 및 디버그·릴리스 빌드, 디버그 Lint가 통과했습니다.
실제 기기의 추가 진입 경로, 중복 뒤로 가기, 재부팅 후 설정 유지 검증은 남아 있습니다.

## 다음 개발 단계

현재 체크포인트를 원격 저장소에 보존한 뒤 별도 브랜치에서 첫 진입 차단을 개선합니다.
접근성 이벤트는 화면이 나타난 뒤 전달되므로, 개선 목표는 첫 영상에서 넘김 조작 없이 자동 이탈하는 것입니다.
Shorts 화면이나 첫 프레임이 잠깐도 표시되지 않는다는 보장은 하지 않습니다.
